# ComputerSciceneJJS

An interactive, visual learning platform built for Class 11 Computer Science students to explore and master web technologies and multimedia concepts.

## 🌟 Key Features

- **Interactive Demos**: Hands-on visual playgrounds for CSS Flexbox, Grid, Box Model, Typography, Colors, and Transitions.
- **HTML Foundations**: Step-by-step interactive structure, forms, tables, semantic tags, and media.
- **Multimedia - Pillars of Multimedia**:
  - In-depth study of the core pillars: **Text**, **Audio**, **Images & Graphics**, **Video**, **Animation**, and **Interactivity**.
  - **Advantages & Disadvantages**: Structured academic points, cognitive models (Paivio's Dual-Coding, Sweller's Cognitive Load Theory), and engineering solutions.
  - **Trade-off Balancer Simulator**: Test real-time cognitive retention vs network bandwidth & hardware overhead across 3G, 4G, and Fiber.
  - **Exam Cheat-Sheet & Model Q&A**: High-yield points prepared for board and school examinations.
  - Dedicated conceptual focus with no code clutter for multimedia topics.
- **Modern Responsive Design**: Optimized for mobile and desktop screens with dark-mode styling.

## 🛠️ Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Styling**: Tailwind CSS & Lucide Icons
- **Motion**: Framer Motion
- **Deployment**: Ready for [Vercel](https://vercel.com/)

## 🚀 Getting Started

### Local Development

```bash
# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

## 📦 Deployment on Vercel

1. Push this repository to GitHub.
2. Import the project into your [Vercel Dashboard](https://vercel.com/new).
3. Vercel automatically detects Next.js — click **Deploy**.
